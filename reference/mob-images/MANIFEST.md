# Mob Images — Dungeons of Eternity (Othergate)

Captured 2026-10-21. All images are **real in-game stills or official footage frames** — no AI generation, no upscaling, no alteration. Fandom files were served as WebP and converted losslessly to the PNG/JPEG format in their filename (same pixels, same dimensions). Everything else is the original file as published.

Intended use: reference for the layered 2.5D hit-dummy stage (`enemies.json` → `layerSpec`) — the owner separates mob from background before the images are dropped into the layer slots.

## No image found

- **Ubermage (clean still)** — Tried: Fandom wiki full image index (226 files; only the lesser Warlock exists), Forsaken Planet wiki Uber Mage article + its info-card image (site unreachable from this network — page fetches and MediaWiki API attempts all timed out, same failure as pass 1), YouTube "Boss of the Week Uber Mage" video (thumbnails obtainable — saved as `ubermage-1.jpg` — but video download is blocked by YouTube's sign-in bot check from this network, all player clients + impersonation tried), Steam store screenshots/trailers and Steam Community screenshots (no Uber Mage appearance). **If the dev team or owner can supply one in-game capture, this is the single biggest gap.**
- **Bat** — Tried: both wikis' image indexes (no bat file exists), Steam store screenshots (13), both Steam trailers frame-scanned, ~67 Steam Community screenshots (recent + top-rated), Fandom teaser images. No identifiable bat in any frame (one teaser frame shows a possible distant bat speck on a vaulted ceiling — far too small to use).
- **Imps (Minion / Warrior / Ranged / Kamikaze)** — Tried: same sweep as Bat. No frame with a clearly identifiable imp; imps are small and fast, and gameplay footage at public resolutions doesn't isolate one.
- **Lost Soul (flaming skull)** — Tried: same sweep. No flaming-skull enemy identifiable in any still or trailer frame.
- **Mimic** — Tried: same sweep. Several ornate chests appear (Steam trailers/store shots) but none is shown in its monster form, so none can be honestly labelled a Mimic.
- **Octoculus Boss (distinct from regular Octoculus)** — The boss's separate floating-eye form appears only cropped behind text in a YouTube thumbnail and as a 3.9 KB wiki thumbnail (`Octo_Oculus.png`, below usable size). The regular Octoculus is covered by `octoculus-2.png`; no clean boss-form image was obtainable.
- **Loot Goblin** — Rare spawn; tried the full sweep above. No appearance.
- **Crypt Guardians** — Sep 2026 Tomb Extraction enemy; community screenshots of Tomb Extraction are almost entirely "Crypt Discovered" loot screens. No guardian visible in any.
- **Golem — Ice variant** — Only the rock/magma forms above were found; no ice golem image in any source tried.
- **Skeleton Archer (dedicated shot)** — The Fandom wiki's `Skeleton_Arch.png` exists but is a 3.4 KB, 90×160 near-black thumbnail — below usable quality, not saved. Archers do appear among the general skeleton shots.
